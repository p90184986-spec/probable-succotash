Project 01 · Learning studio

SEO Mastery Hub v2

An interactive learning studio that combines a structured SEO curriculum, expert-led video lessons, editable HTML exercises, live preview, instant checks, and a completion certificate.

Open live project ↗
Product typeInteractive SEO course
Core experienceLearn → code → verify
StatusLive on Vercel
View live website ↗
Product strengths

Clear progression from learning to proof.

  • Persistent 12-topic roadmap with visible lesson status
  • Video, written explanation, lesson brief, and practice in one workspace
  • Live code editor, browser preview, and four requirement checks
  • Strong visual hierarchy and consistent purple product system
SEO opportunities

Strong product foundation; discoverability can improve.

  • Add a self-referencing canonical URL to the live build
  • Publish a public robots.txt and XML sitemap
  • Give indexable lessons stable URLs with unique titles and descriptions
  • Add suitable Course and educational structured data

Project 02 · Learning operating system

SEO Mastery Hub — Dashboard

A product-style learning command center that brings roadmap progress, lesson momentum, practice labs, projects, achievements, glossary access, and learner statistics into one cohesive dashboard.

Open live project ↗
Product typeSEO learning dashboard
Core experienceTrack → practice → advance
StatusLive on Vercel
View live website ↗
Product strengths

A dashboard that makes momentum visible.

  • Clear next action with lesson progress and overall completion
  • Useful learning signals including XP, streaks, quiz average, and projects
  • Consistent navigation across roadmap, lab, projects, and glossary
  • Distinctive dark-and-lime visual identity with strong card hierarchy
SEO opportunities

Replace development URLs with a public search architecture.

  • Replace the .local canonical, robots, and sitemap domain
  • Move important views from hash URLs to crawlable application routes
  • Add descriptive heading and introductory content to the initial HTML
  • Create unique metadata and relevant structured data for indexable views
